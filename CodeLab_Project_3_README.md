# CodeLab Project 3 — SQL Data Analysis

## Goal
Use SQL queries to extract insights from a dataset.

## Tool
Microsoft SQL Server / SQL Server Management Studio (SSMS)

## Files
- `CodeLab_Project_3_SQL_Analysis.sql` — database/table setup, all 1,200 cleaned rows, and the required analysis queries.
- `CodeLab_Project_3_Data.csv` — cleaned dataset in CSV format.
- `CodeLab_Project_3_Documentation.docx` — project write-up.

## Requirements covered
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT
- SUM
- AVG

## Run
Open the `.sql` file in SSMS and execute it after connecting to a SQL Server instance.
